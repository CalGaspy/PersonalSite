Autonomous Rover

ATmega328PB • C • UltraSonic Sensor • Radio Communication

Project Overview

Our team needed a rover that could be driven remotely and avoid nearby obstacles. I built the ATmega328PB-based control system in C, using radio commands for manual driving and an ultrasonic sensor for obstacle detection. The rover steers left when it detects an object about two inches away.

Key Features

  • Ultrasonic sensor
  • Obstacle Avoidance
  • Wireless Communication

What I Learned

I learned to combine radio commands, PWM motor control, and ultrasonic readings in one embedded C program. Testing both manual driving and obstacle avoidance showed me how sensor input must change the rover's behavior in real time.
